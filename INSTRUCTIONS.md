Детальна інструкція: Налаштування та робота з проєктом Acadoc
0. Організаційний момент
   Написати в приватні повідомлення викладачу свій нікнейм на GitHub.

ЕТАП 1: Підготовка комп'ютера (Робиться один раз)
Якщо у вас вже стоїть XAMPP та Composer, переконайтеся, що увімкнені модулі в php.ini, і переходьте до Етапу 2.

Встановіть XAMPP (PHP + База даних): Завантажте версію для Windows (PHP 8.2+). Після встановлення відкрийте XAMPP Control Panel та натисніть Start біля Apache та MySQL. Вони мають світитися зеленим.

Встановіть Composer: Завантажте з getcomposer.org. При встановленні вкажіть шлях до PHP (зазвичай C:\xampp\php\php.exe).

Увімкніть потрібні модулі PHP:

У XAMPP Control Panel у рядку Apache натисніть Config -> PHP (php.ini).

Через пошук (Ctrl+F) знайдіть ;extension=intl та ;extension=zip.

Видаліть крапку з комою (;) на початку цих рядків, щоб вийшло: extension=intl та extension=zip.

Збережіть файл і обов'язково перезапустіть Apache (Stop -> Start).

ЕТАП 2: Завантаження проєкту
Відкрийте термінал у PhpStorm.

Склонуйте проєкт та перейдіть у папку:

Bash
git clone https://github.com/Barabolikov/acadoc.git
cd acadoc
(Важливо: якщо ви тільки-но встановили Composer, обов'язково перезапустіть PhpStorm перед наступним кроком).

ЕТАП 3: Локальне налаштування проєкту
Встановіть залежності Laravel:

Bash
composer install
Налаштуйте файл конфігурації (.env):

Знайдіть у лівій панелі файлів .env.example.

Скопіюйте його (Ctrl+C -> Ctrl+V) і назвіть нову копію рівно .env (крапка і три літери).

Відкрийте ваш новий .env, знайдіть блок бази даних (десь 11-й рядок) і повністю замініть його на цей (щоб перемкнутися зі sqlite на mysql):

Фрагмент кода
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=acadoc
DB_USERNAME=root
DB_PASSWORD=
Створіть базу даних: Зайдіть у браузері на http://localhost/phpmyadmin, натисніть "Створити базу даних" (New) і назвіть її acadoc.

Згенеруйте ключ безпеки:

Bash
php artisan key:generate
Створіть таблиці в базі даних:

Bash
php artisan migrate --seed
ЕТАП 4: Запуск та Тестова зміна
Перевіримо, чи все працює, зробивши невеличку зміну в коді.

Запустіть локальний сервер командою:

Bash
php artisan serve
Відкрийте в браузері адресу [http://127.0.0.1:8000](http://127.0.0.1:8000). Ви маєте побачити стартову сторінку.

У PhpStorm відкрийте файл resources/views/welcome.blade.php.

Знайдіть будь-який текст (наприклад, заголовок) і допишіть туди своє ім'я або слово "Test".

Оновіть сторінку в браузері — текст має змінитися. Якщо змінився — вітаю, середовище налаштоване ідеально!

ЕТАП 5: Робота над завданням (НАЙГОЛОВНІШЕ)
Ніколи не пишіть код у гілці master! Отримали завдання — створіть для нього окрему гілку:

Bash
git checkout -b feature/news-page
(Замість news-page пишіть назву свого завдання). Тепер ви ізольовані й не зламаєте основний проєкт.

ЕТАП 6: Збереження та відправка коду
Коли код написаний і перевірений локально:

Bash
git add .
git commit -m "Додано сторінку новин та міграцію для неї"
git push origin feature/news-page
ЕТАП 7: Створення Pull Request (PR)
Зайдіть на сторінку репозиторію на GitHub. Ви побачите жовту плашку з пропозицією "Compare & pull request". Натисніть її, напишіть короткий опис того, що ви зробили, і натисніть "Create pull request". Чекайте на перевірку від викладача!
